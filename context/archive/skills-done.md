# Skills done-store — the skills "Fix log"

Shipped `SKILLS_TODO.md` items live here (not in `SKILLS_TODO.md`) so the queue stays **open-only**,
exactly like `roadmap.md`. This file is the skills equivalent of a roadmap item's
`context/features/<area>.md` **Fix log** — the durable per-completion record. The one-line
chronological index across *both* queues stays in `context/done-log.md` (`SHIPPED` blocks).

- **`/skill-forge`** moves a finished `- [ ]` line out of `SKILLS_TODO.md` and appends it here as a
  dated `- [x]` line, **plus** a `SHIPPED` block in `done-log.md`.
- **Newest on top**, same as the live ledger. Append-only; never delete.
